## Full description

TaskLite is a minimal Android task app built around one current task.

The home screen widget is the main surface. It shows your current task, a circular completion bubble, and a quick add action so you can see or update what matters without digging through a larger system.

When you need more room, open the expanded view to:
- add tasks
- edit tasks inline
- reorder active tasks immediately
- search longer lists
- complete tasks and keep them in history
- delete tasks with confirmation

TaskLite is intentionally narrow:
- no accounts
- no sync
- no reminders
- no deadlines
- no sharing
- no projects or categories

Your task list stays on your device. The app works fully offline.

TaskLite also includes an optional ongoing notification if you want the current task visible outside the widget. If you do not want that, leave it off.

Built for a short path to viewing and updating the current task.

## Feature bullets

- `4x1` home screen widget with current task, add action, and circular completion bubble
- Expanded task view with inline editing
- New tasks added to the bottom of the active list
- Drag to reorder active tasks and change priority immediately
- Completed tasks kept in scrollable history
- Uncheck a completed task to create a new active copy while keeping the completed entry
- Delete confirmation before removal
- Local-only storage with offline use
- Optional ongoing notification
- Search for long lists

## Metadata and tone notes

- Keep "optional ongoing notification" phrasing explicit.
- Do not imply cloud backup, cross-device access, or account features.
